# Second-pass static boundary

This pass intentionally distinguishes three levels:

1. **Data-rich client authority** — exact names, levels, descriptions, UI arrays or enum records are embedded and can be mirrored.
2. **Contract-rich** — the client proves the field/schema/UI state the server must populate, but not the production rows/formulas.
3. **Shell/placeholder** — interface exists, but bootstrap text is placeholder/stale and must not be promoted to gameplay authority.

- 41-entry standard-spell filter mapping plus custom Miasmic/Surge builders.
- 23 construction room entries and plank conversion display prices.
- 9 embedded achievement/chapter tasks including reward pairs and progress goals.
- exact timed-task descriptions for Monster Hunter, Boss Hunter, Bounty Hunter and Slaughter.
- broad current settings/control surface.
- Item Library named update/preview contract and equipment slot mapping.
- Clan Wars option/arena surface.
- Hunger Games and several event/minigame state contracts.
- 160 observed class/command-literal pairs in the whole-client command census (not all distinct commands; presence is not proof the production server accepts them).

## Still server/runtime authority

This additional discovery does **not** overturn R1 boundaries. It does not statically supply:

- arbitrary production equipment bonus vectors;
- exact combat damage/accuracy/proc formulas;
- exact projectile timing selected by production combat;
- live shop stock/prices/currencies;
- live marketplace listings;
- production boss-teleport destinations/drop tables;
- exact NPC services/dialogue outcomes;
- constructed-region packet241 templates chosen by production;
- live NPC populations/dynamic world overlays;
- dynamic task assignment/reward rolls;
- event/minigame winner/content/timer selection rules where only the UI state is embedded.
