# Menu-action semantic router — exact-client R3.1 closure

This addendum joins the exact menu-action bytecode census to the already-certified C2S interaction families. It does **not** reinterpret contextual option names as universal semantics. In particular, C2S41 and C2S87 remain contextual even though common interfaces use them for Equip/Drop-like actions.

High-confidence families recovered:

- player options 1..5
- NPC options 1..5
- object options 1..5
- ground-item options 1..5
- widget-item options 1..6
- inventory-item options 1..5
- item-on-player/NPC/item/ground/object
- spell-on-player/NPC/object/ground/item
- generic widget button action 315 -> C2S185(widgetId)

Special local branches 104/169/646/1500/1506 remain separately labelled rather than being forced into ordinary option families.
