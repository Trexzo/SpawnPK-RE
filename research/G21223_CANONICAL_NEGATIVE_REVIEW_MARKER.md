# G21.223 — strict canonical NEGATIVE review-marker fields

Starting point: cumulative [#2697](https://github.com/Trexzo/SpawnPK-RE/pull/2697), exact `2d134ca81a423a52332bf4532ea978cc353abce2`, **550 focused** registered; hosted exact-head CI required (prior 547 test ancestor has been certified). The G21.222 marker reader enforces a 4096-byte bound, NOFOLLOW, regular file and fileKey checks and strict UTF-8, but its final semantic check only required `startsWith(MAGIC)` and `contains(state=ACTIVE...)`. Therefore a malformed concatenated/duplicate, wrong-account or reordered marker could be reported as a valid *diagnostic* representation. A marker's mere existence still denies admission, so this is **defense in depth**, not a proven bypass of admission or any recovery exploit.

G21.223 now parses exactly four ordered newline-terminated fields: historical G21188 magic; `accountSha256=` exact SHA256 of the requested normalized account path; `untrustedSessionNonce=` canonical `UUID.fromString(...).toString()`; and `state=ACTIVE_NEEDS_MANUAL_REVIEW`. Reject duplicates, extra lines, swapped fields, differing account digest, malformed nonce and forged positive-looking adjunct fields. Preserve G21.188 existing wrong-header diagnostic and G21.222 bounded/Nofollow/UTF8 handling. No permissive compatibility fallback for altered diagnostic files, no retirement/rewrite of existing marker, no file deletion.

New focused test forces a real G21.188 marker in an isolated temp directory, mutates the test fixture through seven malformed cases and proves each is refused by **requireReviewMarker**, while **requireNoReviewMarker** still vetoes account admission based on mere existence. Restores original valid bytes for final negative verification. No production account save, login, client, grant or cleanup changes. Manifest **550→551** and dedicated task. This does NOT authenticate an owner epoch or prove actual crash-safe final-save / positive relog; the marker's nonce is explicitly untrusted and its integrity isn't cryptographically authenticated.
