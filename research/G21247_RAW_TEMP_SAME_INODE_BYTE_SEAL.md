# G21.247 — opt-in RAW temp bounded SHA-256 bytes seal

Exact parent [G21.246 #2744](https://github.com/Trexzo/SpawnPK-RE/pull/2744), `cf6fc09fc19085fb2e21ddaf268b24e53e5cff88`, independent hosted CI required. G21.246 validates NOFOLLOW file object key and creation time, yet an adversary can change contents of an existing unique temp in place (including returning its size and mtime) without changing inode identity.

G21.247 computes a SHA-256 digest of the uniquely allocated opt-in RAW temp after serialization with NOFOLLOW streaming and a **64 MiB hard read bound**, checking the object's key+creation-time before and after reading. The same digest and object identity must hold at last pre-move check for all three cooperating RAW paths: FilePlayerRepository.save, primary AccountStore.save, named LocalAccountProfiles.save. Byte mismatch rejects before account rename, preserving current account bytes; failures clean ONLY owned temp. No impact when unique-temp opt-in is disabled. Positive mode still supported by G21.246 regression.

Deterministic test G21.247 mutates the SAME file object with SAME LENGTH and restored mtime at each of three post-temp/pre-publication seams; verifies no replacement and correct exception, no RAW reservations leaks. Manifest **588→589**, task and own exact-head hosted Java11/full Gradle required.
