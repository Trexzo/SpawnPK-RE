Kind enum: `STRICT_PREPARED`, `PREPARED_JOURNAL`, `WORLD_TERMINAL`, `DISK_COMMIT`.

Each new v2 leaf includes canonical account, the exact v1 UUID, kind and BEGIN/COMPLETE stage. Under ONE parent-owned G21.100 lifecycle lock: v1 BEGIN force; typed BEGIN force; real operation; v1 COMPLETE force; typed COMPLETE force. Durable v2 files are create-only hard links, bounded and NEVER deleted/pruned by the application. The only permitted deletion is ephemeral staging temp. If interruption occurs after canonical publication but before completion, typed and/or v1 BEGIN stays unmatched, no rollback or reward permission follows. No ordinary/default/generic/historical writers are newly enrolled.

The `inspectInside` scanner independently verifies the v1 snapshot first, then a bounded maximum 32 typed leaves with NOFOLLOW file-key/size/mtime double-checks and canonical account/UUID/kind/stage payload comparison; every typed leaf must have matching validated v1 stage and each pair must use the SAME kind. Malformed/foreign/orphan/version-unknown/oversized typed records fail closed before another typed opt-in write. A purely v1 legacy/generic attempt with no v2 counterpart yields `MIXED_TYPED_AND_UNTYPED_UNKNOWN` even if every v1 BEGIN is paired. A pending v2 BEGIN blocks new typed attempts. Reports explicitly prohibit authentication, future-writer exclusion, full historical coverage and every cleanup or settlement authority.

The standalone G21.114 Java11 regression advances 413→414. It exercises actual four-kind World account (eight v1 + eight v2 leaves), validates G21.86 disk semantics and unmodified G21.105 portable v1 archive; mixed generic records; plain/default unrecorded cases; fault leaving unmatched typed BEGIN; changed BEGIN/COMPLETE kinds, orphan, cross-account and unknown typed versions; shared 32-v1-leaf capacity veto with preserved disk; no World grant or leaked locks.

**Limit:** typed companions are locally written observational evidence, NOT an authenticated journal or a complete census of all possible writers. Untyped default writes can still occur, and old v1 evidence cannot be retrospectively assigned a trustworthy kind. No crash-power-loss proof, durable rollback, independent identity attestation, historical migration, archival epoch, evidence rollover/pruning, orphan-temp unlink/cleanup, live World settlement/replay/admission/release/client ACK.
