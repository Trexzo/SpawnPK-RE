# G21.218 — pending session OS acquisition must not stall unrelated account admissions

**Parent:** hosted-green G21.217 [#2681](https://github.com/Trexzo/SpawnPK-RE/pull/2681), SHA `d1baa0054b66faa0a5f2736e3217d69099161245`, 534/534 focused, Java11 major55/full Gradle. This is a scheduling/monitor contention mitigation, **not** durable account ownership.

**Production change:** `LocalJvmAccountSessionLease.acquire` previously called G21.185 `FileChannel.open/tryLock` while holding the single global `active` monitor across *all accounts*. With opt-in G21.185, arbitrarily slow filesystem/lock I/O for account A could block unrelated account B's session and cooperating RAW admission. Introduce a per-exact-normalized-path `pendingSessionAdmissions` set, entered under the monitor before the OS call; second same-account session is denied `G21.218 JVM_ACCOUNT_SESSION_ADMISSION_PENDING` and same-path RAW writer denied `G21.218 RAW_WRITE_DENIED_PENDING_SESSION_ADMISSION`. Perform optional G21.185 OS file open+lock OUTSIDE monitor. On success commit Token under monitor and clear reservation; on denial remove reservation; on uncertain OS unlock retain negative local state. Other account paths remain freely admitted. Global OS monitor I/O was also removed from cooperating RAW in prior G21.216.

**Deterministic single-JVM test:** TEST-ONLY no-op by default callback pauses the admission thread after pending marker, before OS I/O. While A is held pending, unrelated B obtains its own real OS session lock; same-file second session and RAW writer are refused. Once released A obtains its real OS lock, with both owners active and zero pending/RAW leaks. No concurrent file mutation, original client changes, replay or marker cleanup.

**Limit:** The test hook is only an intentional deterministic harness; do not set it in production. The session's Token release still closes an OS lock in its own Token monitor path and requires separate attention. Startup opt-ins must precede admission. No durable generation, original-final-save ACK, fencing of uncooperative writers, lock path substitution, safe crash recovery or ACTIVE review retirement. Register **535 focused**. Require exact-head hosted Java11 major55/full Gradle and marker `G21218_PENDING_SESSION_OS_ADMISSION_ISOLATION_PASS`. Draft/unmerged.
