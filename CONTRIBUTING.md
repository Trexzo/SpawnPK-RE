# Contributing

Use focused pull requests and follow the active integration/release target named
in the repository's GitHub coordination queue. Do not assume a permanent
intermediate branch name.

Promote to `main` only through the current cumulative integration/release
process after the required certification and merged-main verification gates are
satisfied.

Required before merge: build passes, regression passes, repo audit passes,
authority/provenance is explicit, and no client binaries/account/build output
are staged.

Keep collaboration private until licensing/provenance review is complete.
